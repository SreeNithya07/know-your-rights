1. Extract this ZIP.
2. Open Command Prompt inside the extracted folder.

TRAIN THE ML MODEL:
cd ml
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
python train.py
copy artifacts\incident_model.joblib ..\backend\app\incident_model.joblib

START BACKEND - open a NEW Command Prompt window:
cd backend
python -m venv .venv
.venv\Scripts\activate.bat
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

START FRONTEND - open ANOTHER NEW Command Prompt window:
cd frontend
npm install
npm run dev

Open in browser:
http://localhost:5173

Backend API docs:
http://localhost:8000/docs

Emergency in India: call 112.
